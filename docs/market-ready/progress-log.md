## 2026-07-27 第二批：内容发布审核、绿动有约并发与长视频课程

### 已完成代码提交

1. 绿动有约业务可靠性：
   - 公开列表和未通过申请人的详情不再返回完整联系方式；
   - 发起人或审核通过申请人才可查看必要联系方式；
   - 自动通过和人工审核通过均使用条件更新原子占用名额；
   - 防止重复审核、并发超员、客户端伪造发布者和申请人；
   - 申请时间、活动状态、重复申请和申请自己活动均由后端校验。
2. 社区内容发布审核：
   - 底部发布只创建图文和十分钟以内短视频；
   - 发布者由登录态确定，客户端 `userId/status` 不再可信；
   - 新内容进入待审核，审核通过后才写公开缓存、达人主页和绿豆奖励；
   - 支持审核通过、驳回、下架和作者修改后重新提交；
   - 用户只能删除自己的内容；
   - 增加审核原因、审核人、审核时间、正式发布时间和媒体处理状态；
   - 运营分页返回作者昵称、头像和分类名称，待审核内容优先排序。
3. 内容视频媒体处理：
   - 封面生成结果回写 `PROCESSING/READY/FAILED`；
   - 处理未完成或失败时不能误判为可审核内容；
   - 生成封面后同步更新内容封面字段。
4. 长视频课程底座：
   - 保留 `ldqc_training` 课程主表，新增章节、课时、播放授权和学习进度；
   - 课程目录不返回原始视频 URL；
   - 免费、试看或已授权用户通过五分钟播放令牌获取视频；
   - 学习进度按用户和课时幂等保存，旧心跳不会覆盖更靠后的断点；
   - 课程发布前校验课时和媒体状态；
   - 长视频远程截帧并探测时长，避免应用服务器完整下载视频；
   - 增加课程基础设置、章节课时、发布下架、用户搜索和人工授权接口。
5. 安全配置：
   - 取消管理端内容分页匿名放行；
   - 仅放行公开内容、课程目录、试看令牌和短时播放链接；
   - 学习进度和正式业务操作继续要求登录。
6. SQL 与菜单：
   - 内容审核生命周期迁移；
   - 长视频课程底座迁移；
   - 内容审核、课程管理和课程内容工作台菜单与按钮权限脚本。
