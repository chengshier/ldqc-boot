## 三、SQL 执行前置条件

1. 使用 MySQL 5.7 测试库完整备份后执行。
2. 按 `docs/market-ready` 与 `doc/sql` 中的执行顺序逐份执行。
3. 结构迁移、菜单权限、历史数据修复和 UAT 数据必须分开执行。
4. 每份 SQL 执行后检查字段、唯一索引、历史数据状态和可重复执行性。
5. 未在测试库执行成功前，不得进入生产库。

## 五、Draft PR 转为可审核的条件

1. 三端自动验证持续通过。
2. SQL 在测试库执行并形成记录。
3. P0/P1 主业务流程通过多角色联调。
4. 微信开发者工具和至少一轮真机回归完成。
5. 遗留问题明确分为上线阻断和后续迭代。
6. 由项目负责人确认后再转为 Ready for review，当前不自动合并 `master`。
